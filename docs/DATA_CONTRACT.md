# Контракт будущих данных

В templates находятся только CSV-заголовки. Реальные строки не предоставлены. Поля ниже — начальная спецификация, которую нужно реализовать и уточнять версионированно.

## Сессии

Одна строка sessions.csv — один приём пищи в одной школе. session_id уникален.

| Поле | Значение |
|---|---|
| session_id, school_id | Технические идентификаторы без ФИО учеников |
| service_date | Локальная дата приёма пищи, YYYY-MM-DD |
| timezone | Часовой пояс школы, не часовой пояс сервера |
| meal_type | Контролируемый справочник типов приёма пищи |
| attendance_count | Измеренная посещаемость, nullable; не заменяет спрос |
| meals_requested | Непосредственно зарегистрированные запросы на питание, nullable |
| meals_served | Количество выданных приёмов пищи, nullable |
| demand_censored | true/false/unknown: мог ли дефицит скрыть часть спроса |
| evidence_status | Для исходных записей только REAL_OBSERVED либо SYNTHETIC |
| study_phase | CALIBRATION, BASELINE, SHADOW, INTERVENTION, FOLLOWUP |
| source_ref | Ссылка/идентификатор подтверждающего источника |
| observed_at, recorded_at | Время события и время появления записи с offset |

## Наблюдения по блюдам

Одна строка observations.csv — измерение блюда в сессии; не индивидуальная тарелка ученика.

| Поле | Значение |
|---|---|
| observation_id, session_id, dish_id | Идентификаторы и связь с сессией |
| prepared_mass_g | Измеренная масса готовой еды, nullable |
| served_mass_g | Измеренная масса выданной еды, nullable |
| production_waste_g | Отходы приготовления, nullable |
| serving_waste_g | Отходы раздачи, nullable |
| plate_waste_g | Остатки на тарелках, nullable |
| avoidable_waste_g | Только отдельно классифицированные предотвратимые отходы, nullable |
| avoidability_status | UNCLASSIFIED, PARTIALLY_CLASSIFIED, CLASSIFIED |
| evidence_status, source_ref | Статус происхождения и источник |
| observed_at, recorded_at | Время наблюдения и появления записи с offset |

Пустое поле — неизвестное значение, не ноль. В шаблонах массы заданы в граммах; UI/импорт могут принимать kg только с явной конвертацией. Не складывай массу сырых ингредиентов с массой готовой еды и не требуй ложного баланса между ними. Опиши точки взвешивания, тару, съедобную часть и границы категорий в протоколе до реального сбора.

## Валидация и происхождение

- Проверяй неотрицательность, конечность чисел, целочисленность счётчиков, временные поля, ссылки, дубликаты и согласованность измерительной базы.
- При served_mass_g > prepared_mass_g не исправляй запись молча: отклони либо потребуй документированное объяснение дополнительных партий/различий базы.
- Не выводи спрос из посещаемости или факта выдачи. При цензурировании спроса обычная точность прогноза выдачи не доказывает прогноз полного спроса.
- В backtest учитывай recorded_at: будущие исправления не должны попадать в исторические признаки, если на момент решения их ещё не было.
- Дополнительные серверные поля: revision_id, supersedes_revision_id, created_by, quality_flags, dataset_version и события аудита. CSV не заменяет полный серверный контракт.
- VERIFIED создаётся отдельной процедурой с проверяющим, методом и источником; синтетика не допускается. Исправление VERIFIED требует повторной проверки.
- Производные артефакты содержат свой тип PREDICTED/SIMULATED и ссылки на происхождение входов. Расчёт из SYNTHETIC не становится реальным фактом.

## Авторитетные показатели

| Показатель | Формула и условие |
|---|---|
| UneatenIndex | plate_waste_g / served_mass_g × 100%, при согласованной базе и положительном знаменателе |
| OverproductionRate | (prepared_mass_g − served_mass_g) / prepared_mass_g × 100%, при согласованной базе |
| TotalMeasuredWaste | production_waste_g + serving_waste_g + plate_waste_g, только когда все категории измерены и не пересекаются |
| WastePerMeal | сумма явно классифицированных avoidable_waste_g / meals_served, при достаточной полноте |
| ServiceLevel | min(meals_served / непосредственно наблюдаемые meals_requested, 1) × 100%; цензурирование показывать отдельно |
| CostWastePerMeal | стоимость явно классифицированных предотвратимых отходов / meals_served, только с проверяемыми источниками стоимости |

Не усредняй проценты блюд для получения процента школы: агрегируй совместимые числители/знаменатели. Не суммируй session-level счётчики один раз на каждое блюдо. Нулевой знаменатель или недостающие поля → unavailable с причиной. Стоимость потерь не называется денежной экономией.

Стоимость, нормативы, документы финансового реестра, согласования и школьные потребности потребуют отдельных сущностей. Ни налоговые/правовые разрешения, ни реальные значения норм в шаблонах не заданы. Для каждой политики нужны источник, юрисдикция, версия, срок действия, статус проверки и применимость.
