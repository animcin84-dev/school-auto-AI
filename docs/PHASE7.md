## 1. Что создано
1. **Откалиброванный SYNTHETIC-генератор v2** (`gen-calibrated`): порции —
   Приложение 7 Санправил РК (NORM_KZ), доли отходов — исследование 78 школ
   Италии (EMPIRICAL_STUDY), sanity — Латвия 142–268 г/день/ребёнка; манифест
   происхождения каждого параметра; фактическая проверка: 96.8 г/ребёнка/день
   против итальянских измеренных 89.9 г (обед без хлеба/фрукта).
2. **Среда OPEN** (третий маркер среды): чужие реальные измерения, только
   REAL_OBSERVED; verify/approve/execute/фазы запрещены кодами
   E_*_NOT_AVAILABLE_OPEN; selfcheck расширен; полная изоляция от REAL и DEMO.
3. **Импорт реальных открытых данных**: ридер xlsx на stdlib
   (sra/ingest/xlsx_min.py) + адаптеры Zenodo 20825233 (Финляндия) и 18441715
   (Латвия, CC BY 4.0); команда import-open; аудит-копии CSV.
4. **Сравнение фаз** (`eval-compare`): Welch (точное p через неполную бета-
   функцию) + Манн–Уитни на stdlib; меню-выравнивание; design-check.
5. **Пакет пилота для школы КЗ** (`pilot-package`): 5 документов, генерируются
   кодом — условия ворот в текстах всегда синхронны sra/phases.py.
6. **Прогноз едоков с ML** (`forecast-diners`): причинные признаки, оценка
   rolling-origin (3 окна), кандидаты moving_average5/weekday3/menu_history/
   ridge(±trend)/sklearn_gbdt; конформальные интервалы: static q80, скользящее
   окно, ACI; выбор по измеренному MAE; model cards.
7. **Композитный прогноз** (`forecast-composite`): «масса = едоки × г/едока»
   vs прямой; оценка по MAE И по стоимости решения (новостная формула).
8. **Контроль качества** (`quality-check`): полнота, выбросы по MAD, пропуски
   учебных дней, аномалии счётчиков; кросс-чек с первоисточником FI.
9. **KZ-календарь** (data/kz-calendar.json, ориентировочные даты с пометкой) и
   **алерты питания** (`alerts`): порог несъедаемости 30% из нацстандарта РК.
10. **Импорт внешних CSV по карте** (`import-map`): универсальный вход для
    выгрузок («Соцкошелёк» и др.), атомарный, с построчными ошибками.
11. **Демо-шаг 7e**: весь ML-трек в одной команде демо, с честной пометкой
    «на синтетике — только механика».
12. Документы: docs/OPEN_DATA_PLAN.md, docs/ROADMAP.md, docs/INTERVENTIONS.md,
    docs/pilot-package/*.

## 2. Команды реально выполнены и результаты
- `import-open` (реальные файлы): FI 155/155 дней, 0 пропусков, md5 источника
  сверен с Zenodo; LV 20 сессий/60 блюд, кросс-чек итогов 0 расхождений.
- `eval-compare` (FI, реальные): −4.07 г/едока (−17.45%), Welch p=0.048,
  Манн–Уитни p=0.024, меню-выравнивание −3.76 г; дизайн: ~65 дней/группу.
  Найдена ошибочная ячейка в производной колонке авторов (2025-03-17:
  8.25 против вычисляемых 34.21) — теперь находит `quality-check` автоматически.
- `UneatenIndex` системы воспроизвёл авторские проценты LV (16.07/17.56/
  15.05/12.71%) — сверка формул и агрегации на чужих реальных данных.
- `forecast-diners` (FI, реальные, rolling-origin 3 окна): MAE
  menu_history 34.3, MA5 34.7 (±2.9), sklearn_gbdt 37.4, ridge_notrend 38.0,
  ridge 77.5 (±104 — нестабилен с трендом). **ML-кандидаты пока не проходят
  наш гейт на этом датасете**; single-holdout POC (−11%) был оптимистичен —
  оценка в системе заменена на rolling-origin по умолчанию.
- `forecast-composite` (FI, реальные): по MAE паритет (прямой 2020 vs
  композит 2033 г); по стоимости решения лучше композит (2058 vs 2069
  тыс. KZT_DEMO/день) — ранжировки MAE и «цены для кухни» расходятся.
- `demo --seed 42` и `--seed 60`: полный конвейер, включая 7e; 271 тест OK.

## 3. Какие проверки недоступны
- Точность прогноза и эффект вмешательства на школе КЗ — нет данных (и не
  будет заявлено до этапа 5b).
- Интеграция «Соцкошелька» — формат выгрузки не подтверждён образцом;
  строить адаптер по догадкам запрещено (готов import-map).
- Обучение прогноза под решение (DFL) — нужна REAL-история.
- Лицензия FI-записи — точный тип не подтверждён (у LV — CC BY 4.0 из файла).

## 4. Какие данные искусственные
- calibrованный генератор (DEMO) и демо-шаг 7e: SYNTHETIC с source_ref
  synthetic-calibrated:v2; ML на синтетике проверяет ТОЛЬКО механику
  (причинность признаков, схему валидации, конформальные интервалы).
- Мок-выгрузка «Соцкошелька» в тестах import-map — тестовые данные.

## 5. Что неизвестно
- Реальные распределения школы КЗ (порции подтверждены нормами; отходы,
  посещаемость, спрос — только локальными измерениями).
- Переносимость долей отходов Италии/Финляндии/Латвии на КЗ — не доказана.
- Формат выгрузки «Соцкошелька», фактические даты каникул конкретной школы.

## 6. Следующий этап

  распределения спроса (механика), отчёт для директора школы на основе демо.
