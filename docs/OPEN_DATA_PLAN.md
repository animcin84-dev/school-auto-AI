# Открытые данные и откалиброванная синтетика (этап 5b — подготовка)

Дата: 2026-10-22. Статус: подготовка к реальным данным. Реальных данных школы КЗ
в проекте НЕТ; нижеследующее не заменяет этап 5b (согласие школы, протокол, сбор).

## Вариант 1 (реализован): откалиброванный SYNTHETIC v2

`python3 -m sra gen-calibrated --dir data/demo-calibrated --seed 2026 --days 90`

Каждый параметр манифеста (`manifest.json → calibration`) имеет класс:
- `NORM_KZ` — официальные рекомендации РК: Приложение 7 к Санитарным правилам
  «Санитарно-эпидемиологические требования к объектам образования» (приказ МЗ РК
  от 28.08.2020 № ҚР ДСМ-98/2020): первое 200–250 г, гарнир 100–150, мясо/рыба
  80–150, салат 60–100, напиток 200 г (6–11 лет); состав обеда — по Правилам
  организации питания (приказ МОН РК № 235, 08.06.2020).
- `EMPIRICAL_STUDY` — опубликованные прямые взвешивания ДРУГИХ стран:
  Италия (Sustainability 2025, 17(17):7836; 78 школ, методология EC 2019/1597):
  доли отходов тарелок по типам блюд 17.7–21.8%, невыданное 2.9–4.7%;
  Латвия (Sustainability 2022, 14(7):4046): 142–268 г/день/ребёнок — sanity-диапазон;
  Финляндия (Zenodo 20825233): дизайн «день = строка», меню-цикл.
- `ASSUMPTION` — явные допущения (производственные отходы 3–6%, частота дней
  нехватки, контингент 120): источников не найдено, проверяются на этапе 5b.

Проверка правдоподобия: сгенерированные отходы тарелок ≈ 97 г/ребёнок/день при
итальянских измеренных 89.9 г/день (у них обед с хлебом/фруктом, у нас — без).

Честные границы: это SYNTHETIC — проверка кода и реалистичность сценария.
EMPIRICAL_STUDY-доли не переносимы на школу КЗ без локальных измерений.

## Вариант 2 (инфраструктура ГОТОВА, файлы ещё не переданы): датасеты Zenodo

Лицензии: Латвия — **CC BY 4.0** (подтверждена Read_me записи); Финляндия —
запись открыта, точный тип лицензии подтвердить по странице при скачивании.

1. **Финляндия, 155 учебных дней, 2024–2025** — Zenodo record 20825233,
   файл «Food waste data school Finland 2024-2025.xlsx» (31.2 kB):
   https://zenodo.org/records/20825233/files/Food%20waste%20data%20school%20Finland%202024-2025.xlsx?download=1
   Переменные: PW (кг, отходы тарелок/день), PW/g/diner, KSW (кухня+раздача),
   KSW/g/diner, DINERS, MENU (1–25). Baseline 135 дней + intervention 20.
2. **Латвия, 4 школы Резекне, декабрь 2023** — Zenodo record 18441715
   (124.7 kB + Read_me). Прямые взвешивания индивидуальных тарелок, 1–7 классы,
   частично pre-served модель; общие ёмкости исключены авторами.
   Переменные (Read_me): School_ID, Measurement_period, Student_group,
   School_level, Age_group, Meal_type, Served_food_g, Plate_waste_g.

### Как передать файлы
Файлы нужно ПРИЛОЖИТЬ К СООБЩЕНИЮ в чате (загрузка в песочницу напрямую
из интернета невозможна: сеть ограничена github/npm/pypi, zenodo.org
недоступен для скачивания).

### Что уже реализовано (коммит с этим файлом)
- **Среда `OPEN`** (третий маркер среды наряду с REAL/DEMO): чужие реальные
  измерения. Принимает только REAL_OBSERVED; verify/approve/execute/фазы —
  запрещены с явными кодами (E_VERIFY_NOT_AVAILABLE_OPEN,
  E_APPROVALS_NOT_AVAILABLE_OPEN, E_EXECUTION_BLOCKED_OPEN,
  E_PHASES_NOT_AVAILABLE_OPEN); selfcheck проверяет OPEN-хранилища на отсутствие
  синтетики и исполнений. Полностью изолирована от REAL (наша школа) и DEMO
  (наша синтетика).
- **`sra/ingest/xlsx_min.py`** — ридер xlsx стандартной библиотекой
  (zipfile+XML: sharedStrings/inline/числа/даты-сериалы).
- **`sra/ingest/zenodo_fi.py` / `zenodo_lv.py`** — адаптеры: tolerant-сопоставление
  заголовков, честные пропуски строк с причинами, kg→г конвертация,
  `source_ref="zenodo:<id>:v1"`, notes с происхождением; отчёт содержит header_raw
  (исходную шапку файла) — расхождения с фактическим файлом видны сразу.
- **`python3 -m sra import-open --db <db> --dataset finland|latvia --file <xlsx>`** —
  валидация → CSV-копии для аудита (`.audit.csv`) → атомарный импорт в OPEN-БД.
- Тесты `tests/test_ingest_open.py` (11): round-trip ридера, оба адаптера,
  честные пропуски, guard-коды OPEN-среды, метрики на REAL_OBSERVED.

### Честные ожидания по результатам импорта
- Финляндия: все 6 метрик UNAVAILABLE с конкретными причинами (нет served/prepared
  масс, нет avoidable-классификации, спрос не наблюдается); прогноз DATA_NOT_READY.
  Ценность — проверка всего конвейера на РЕАЛЬНЫХ распределениях (шум, пропуски,
  intervention-фаза 135/20).
- Латвия: UneatenIndex вычислим (plate/served на группу); OverproductionRate,
  TotalMeasuredWaste (нужны все 3 категории), WastePerMeal (нужна avoidable),
  ServiceLevel (нужен наблюдаемый спрос) — UNAVAILABLE с причинами; прогноз —
  при достаточном числе дней в файле.
- Точные заголовки реальных файлов могут отличаться от Read_me («indicative
  variables»): отчёт импорта печатает фактическую шапку; при расхождении
  соответствия правятся точечно за один шаг.

## Что остаётся неизвестным
- Точный тип лицензии финской записи (проверить при скачивании).
- Фактические заголовки/структура листов обоих xlsx (строки Латвии могут быть
  агрегатами периода без дат — тогда прогноз честно останется DATA_NOT_READY).
- Любые параметры школы КЗ (порции подтверждены нормами; отходы — только
  локальными измерениями этапа 5b).
